# Invasion Mod for Minecraft 1.20.1 (Forge)

Minecraft 1.6.4 / 1.7.10 の名作 **Invasion Mod** を Minecraft **1.20.1 (Forge 47.x)** 向けに作り直したポートです。
元のソースコードやアセットは使っておらず、ゲームプレイを参考にして一から実装しています。

## 遊び方

1. **ネクサス** をクラフトして設置する。
2. ネクサスを右クリックして GUI を開き、上のスロットに触媒を入れる。
   * **ネクサス触媒**: ウェーブモード（ウェーブ 1 から）
   * **強力な触媒**: ウェーブモード（ウェーブ 10 から）
   * **安定エネルギー場**: 継続モード（定期的な襲撃 + リフトフラックスの自動生成）
3. ネクサスから一定距離（初期値 45 ブロック、ネクサスアジャスターで変更可）の円周上に侵略者が出現し、ネクサスへ向かってくる。
4. 侵略者はネクサスへの道をふさぐブロックを **掘り進み**、ピッグエンジニアは **柱や橋を建てる**。ネクサスの HP が 0 になると侵略は失敗。
5. ウェーブを撃退すると報酬（リフトフラックス、5 ウェーブごとにスモールリフト）が下のスロットに出る。
6. **減衰剤** で次のウェーブを 1 つ下げ、**強力な減衰剤** で侵略を安全に終了できる。

侵略中はネクサスを壊せません。進行状況は画面上部のボスバーにも表示されます。

## 侵略者

| Mob | 特徴 |
| --- | --- |
| 侵略ゾンビ | 基本の侵略者。障害物を掘り進む。高ウェーブでは武器・防具を装備 |
| 侵略クモ | 速く、壁を登る |
| 侵略スケルトン | 近くのプレイヤーを弓で狙う |
| ピッグエンジニア | ハンマーで素早く掘り、柱と橋を建てる |
| 侵略クリーパー | ネクサスの横で自爆し大ダメージ |
| インプ | 小さく速い。火炎耐性があり攻撃で炎上させる |
| スローワー | 巨体。岩を投げてブロックを壊し、ネクサスにもダメージ |

どの侵略者も日光で燃えません。ウェーブが進むと体力と攻撃力が上がります。

## アイテム

* **フェイズクリスタル / リフトフラックス / スモールリフト**: 素材
* **触媒混合物 → ネクサス触媒**, **強力な触媒混合物 → 強力な触媒**, **安定触媒混合物 → 安定エネルギー場**（かまどで精錬）
* **減衰剤 / 強力な減衰剤**
* **ネクサスアジャスター**: 停止中のネクサスの出現半径を変更（スニークで減少）
* **プローブ**: ブロックが掘られるまでの時間、またはネクサスの状態を表示
* **インフューズドソード**: 攻撃でチャージ、満タンで右クリックすると回復
* **灼熱の弓**: 燃える矢を放つ
* **強靭なダガー / エンジニアのハンマー**: 武器
* **リフトトラップ / フレイムトラップ**: 敵対 Mob が踏むと発動する罠。発動後は空のトラップに戻る

レシピは JEI などで確認するか `src/main/resources/data/invasion/recipes` を参照してください。

## 設定

`config/invasion-common.toml` で出現半径、ネクサスの HP、同時出現数、ブロック破壊の有無、掘れる硬さの上限などを変更できます。
`invasion:dig_immune` ブロックタグに入っているブロックは侵略者に掘られません。

## ビルド

```sh
./gradlew build
```

成果物は `build/libs/invasion-<version>.jar` に出力されます（Java 17 が必要）。
GitHub Actions でもビルドされ、jar がアーティファクトとしてアップロードされます。

## 元の Mod からの主な違い

* Mob の見た目はバニラのモデル・テクスチャを流用しています（スローワーは大型ゾンビ、ピッグエンジニアはゾンビピグリン、インプはハスクの子供）。
* トラップはエンティティではなくブロックとして実装しています。
* Burrower、Vulture（巨大鳥）、Egg、Wolf 系などは未実装です。
